## 📖 Overview

**AQWAFLEX** is a responsive corporate website designed to present a premium mattress brand with an elegant and modern user experience. It showcases high-quality sleep products, company background, business services, and contact details while adhering to modern web development best practices.

Built with cutting-edge technologies like **Next.js**, **React**, and **Tailwind CSS**, AQWAFLEX provides seamless navigation, lightning-fast dynamic load times, and an intuitive UI/UX tailored for recruiters, developers, and potential enterprise clients.

## ✨ Features

- 🏠 **Modern Landing Page**: High-impact visual hero banner, clear calls to action, and brand narrative.
- 🛏️ **Product Showcase**: Detailed matrix presenting premium mattresses with specifications and features.
- 📱 **Fully Responsive Design**: Fluid mobile, tablet, and desktop layouts across all screen resolutions.
- ⚡ **Fast Performance**: Optimized rendering pipeline leveraging Next.js App Router and Server Components.
- 🎨 **Modern UI/UX**: Aesthetic dark/light themes, sleek typography, micro-interactions, and glassmorphism styling.
- 📞 **Contact Section**: Interactive contact form and business inquiry portal.
- 🖼️ **Image Gallery**: High-resolution gallery displaying ergonomic design and material craftsmanship.
- 🔍 **SEO Optimized**: Pre-rendered semantic HTML tags, structured metadata, and open graph configurations.
- 🌙 **Smooth Animations**: Seamless transitions and dynamic elements powered by Framer Motion.

## 🚀 Getting Started

To set up a local development copy of **AQWAFLEX**, follow these simple steps:

### 1. Clone the repository

```bash
git clone https://github.com/ObaidDev-Ait/AQWAFLEX.git
```

### 2. Navigate to the project directory

```bash
cd AQWAFLEX
```

### 3. Install dependencies

```bash
npm install
```

### 4. Run the development server

```bash
npm run dev
```

### 5. Open in your browser

Open `http://localhost:3000` with your browser to view the application live.

## ⚡ Performance

AQWAFLEX is engineered for enterprise-grade performance and accessibility:

- 🚀 **Server Components**: Reduces JavaScript bundle size delivered to the client for faster TTI (Time to Interactive).
- 🖼️ **Image Optimization**: Utilizes `next/image` for automatic format conversion (AVIF/WebP), resizing, and lazy loading.
- ⏳ **Lazy Loading**: Deferred loading of heavy sub-components and animation modules.
- 📱 **Responsive Layouts**: Zero layout shifts (CLS) across mobile, tablet, and desktop viewports.
- 🔍 **SEO Metadata**: Full metadata suite including Open Graph and Twitter Card tags.
- ⚡ **Fast Loading**: Optimized asset distribution via edge CND routing.
